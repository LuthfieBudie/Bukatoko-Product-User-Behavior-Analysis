# Bukatoko-Product-User-Behavior-Analysis
A comprehensive analysis of cross-platform user behavior and feature effectiveness on the Bukatoko e-commerce app operating in Southeast Asia, the United States, and Australia. This project aims to identify user interaction patterns and measure sales funnel efficiency.

Tools:
SQL: Data cleaning, filtering, and metric aggregation.
Google Sheets: Initial data exploration and logic documentation.
Power BI: Interactive visualization and platform trend analysis.

Key Insight:
High Cross-Device Behavior: Of the total 2,000 unique users, the device reach reached > 4,000 (Android: 1,813, iOS: 1,728, Desktop: 795). This indicates that Bukatoko users are highly active in switching devices.
Conversion Funnel: The search feature generated a 1.03% Search-to-Cart Conversion Rate. This indicates a significant opportunity for optimizing the search algorithm to increase shopping interest.

Repository Structure:
sql_queries: A collection of SQL queries for data cleaning and metric calculations.
visualizations: Dashboard screenshots and visual reports.
dataset: Documentation of the dummy dataset used.
