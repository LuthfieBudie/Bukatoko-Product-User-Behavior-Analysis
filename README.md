# Bukatoko-Product-User-Behavior-Analysis
Analisis komprehensif terhadap perilaku pengguna lintas platform (cross-platform) dan efektivitas fitur pada aplikasi e-commerce Bukatoko yang beroperasi di Asia Tenggara, Amerika Serikat, dan Australia. Proyek ini bertujuan untuk mengidentifikasi pola interaksi pengguna dan mengukur efisiensi corong penjualan (sales funnel).
